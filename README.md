# CreditWise — End-to-End Loan Approval System

CreditWise is a full-stack loan approval system powered by a **Decision Tree Classifier** machine learning model. It integrates a React frontend with a FastAPI backend to assess loan eligibility in real-time based on applicant, financial, employment, and loan details.

---

## 🏗️ Architecture

```
React Frontend (Vite + TanStack) 
        ↓  POST /predict (JSON Payload)
FastAPI Backend (http://127.0.0.1:8000)
        ↓  Inference Pipeline
Pre-trained Decision Tree Model (creditwise_decision_tree.pkl)
        ↓  Prediction & Probability
React Result Card (Approved / Rejected)
```

## 🤖 Machine Learning Model Details

- **Dataset**: `loan_approval_data.csv`
- **Target Column**: `Loan_Approved` ('Yes' -> `1`, 'No' -> `0`)
- **Classifier**: `DecisionTreeClassifier(random_state=42)`
- **Preprocessing Pipeline**:
  - **Numerical Features** (`Applicant_Income`, `Coapplicant_Income`, `Age`, `Dependents`, `Credit_Score`, `Existing_Loans`, `DTI_Ratio`, `Savings`, `Collateral_Value`, `Loan_Amount`, `Loan_Term`): Imputed using `SimpleImputer(strategy='mean')`.
  - **Ordinal Features** (`Education_Level`): Imputed with `most_frequent` and encoded (`Graduate` -> 0, `Not Graduate` -> 1).
  - **Categorical Features** (`Employment_Status`, `Marital_Status`, `Loan_Purpose`, `Property_Area`, `Gender`, `Employer_Category`): Imputed with `most_frequent` and encoded using `OneHotEncoder(drop='first')`.
  - **Feature Scaling**: Scaled using `StandardScaler()`.
- **Performance**:
  - **Accuracy**: ~92.1%
  - **Precision**: ~91.1%
  - **Recall**: ~83.6%
  - **F1 Score**: ~87.2%

> **Notebook Bug Fix Documented**: In `Main.ipynb`, the original evaluation cell for Decision Tree mistakenly used `y_pred = gnb_model.predict(...)`. This was corrected to `y_pred = clf.predict(...)` to accurately compute Decision Tree predictions.

## 🚀 Getting Started

### 1. Backend Setup & Run

Navigate to the `backend` directory, install dependencies, and start the FastAPI server using `uvicorn`:

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

The backend server will run on:
- **Base URL**: `http://127.0.0.1:8000`
- **Swagger API Docs**: `http://127.0.0.1:8000/docs`

### 2. Frontend Setup & Run

In a separate terminal, navigate to the `Frontend` directory, install Node dependencies, and start the Vite development server:

```bash
cd Frontend
npm install
npm run dev
```

The frontend application will be accessible at:
- `http://localhost:8080/` (or the port assigned by Vite)

## 📡 API Endpoints & Specification

### `GET /`
Returns the status message of the CreditWise backend service.

**Response**:
```json
{
  "message": "CreditWise API is running"
}
```

---

### `POST /predict`
Processes applicant data and returns the loan approval prediction generated by the saved Decision Tree model.

#### **Request Body Example**:
```json
{
  "Applicant_ID": "APP-10234",
  "Age": 35,
  "Gender": "Male",
  "Marital_Status": "Married",
  "Dependents": 1,
  "Education_Level": "Graduate",
  "Applicant_Income": 15000,
  "Coapplicant_Income": 4500,
  "Savings": 35000,
  "Loan_Amount": 18000,
  "DTI_Ratio": 0.22,
  "Credit_Score": 760,
  "Existing_Loans": 1,
  "Employment_Status": "Salaried",
  "Employer_Category": "Government",
  "Collateral_Value": 40000,
  "Loan_Term": 36,
  "Loan_Purpose": "Home",
  "Property_Area": "Urban"
}
```

#### **Response Example**:
```json
{
  "prediction": 1,
  "result": "Approved",
  "probability": 100.0,
  "approval_probability": 100.0
}
```
